# 알고핏(AlgoFit) 졸업심사 발표 그래프

「코딩 문제 풀이 이력 분석과 LLM을 활용한 맞춤형 학습 지원 시스템」의 졸업심사 발표 자료(5차)에 쓴 그래프 원본과, 그래프를 그린 코드입니다.

- 팀: 김서진, 양지원, 장서은, 홍연의 (한양여자대학교 빅데이터과)
- 지도교수: 하효동
- 산업체 멘토: 커리어케어 이효영 상무

## 폴더 구성

```
algofit_figures/
├── README.md
├── make_figures.py          # 그래프 5개를 모두 다시 그리는 코드
└── figures/                 # 발표에 넣은 그래프 원본 (PNG, 300dpi)
    ├── fig1_문제제기_정답률과_공식실력점수.png   → 2쪽 01 개요_문제 제기
    ├── fig2_전체판정.png                         → 6쪽 03 분석 결과 (왼쪽)
    ├── fig3_약한분야_적중률.png                  → 6쪽 03 분석 결과 (가운데)
    ├── fig4_예측정확도_AUC.png                   → 6쪽 03 분석 결과 (오른쪽)
    └── fig5_학습유형_Kmeans.png                  → 7쪽 03 분석 결과_학습 유형
```

## 그래프 설명

| 그림 | 내용 | 확인한 숫자 |
|---|---|---|
| fig1 | 정답률 구간별 학습자 수(왼쪽)와, 그중 정답률 95% 이상인 학습자를 펼쳐 본 공식 실력 점수 분포(오른쪽). 95% 이상 막대와 오른쪽 그래프를 같은 주황색과 화살표로 연결함 | 왼쪽 막대 합 8,502명, 오른쪽 막대 합 4,081명, 정답률 90% 이상 79.3%, 점수 범위 360~3,803점 |
| fig2 | 공식 실력 점수와 비교한 전체 판정 (합이 전체 인원이라 도넛으로 표시) | 실력 부족 1,134 / 점수만큼 5,213 / 점수 이상 2,155 (합 8,502명) |
| fig3 | 고른 약한 분야가 다음 기간에도 약했던 비율 | 우리 진단 42.8%, 정답률 낮은 순 43.0%, 무작위 35.1% |
| fig4 | 다음 기간 정답 예측 정확도(AUC). '이전 → 이후'를 점과 화살표로 표시함 (가로축 0.695~0.768) | 공식 실력 점수 0.722, 평소 실력 점수 0.743, 공식 점수만 0.723, 진단 추가 0.732 |
| fig5 | 풀이 습관 지표 9개를 '유형이 가장 잘 나뉘는 2개 축'(선형 판별 분석, LDA)으로 요약해 학습자를 점 하나로 표시함. 유형마다 도형을 다르게 함(● ▲ ■ ◆). 큰 도형은 각 묶음의 평균 위치이고, 학습자 2,000명을 무작위로 골라 표시함. 그리기 전에 모든 학습자가 가장 가까운 K-means 중심의 유형과 같은지 확인함(assert) | 로직 점검형 3,788 / 도전적 시행착오형 2,402 / 효율 개선 필요형 1,606 / 문법 실수·빠른 재제출형 706명 |

그래프 크기(인치)를 슬라이드에 넣는 크기와 같게 정했습니다. 그래서 코드에 적은 글자 크기(pt)가 슬라이드에서도 그대로 보입니다.

## 다시 그리는 방법

```bash
pip install pandas numpy matplotlib
python make_figures.py <capstone 분석 폴더> <Pretendard 글꼴(.otf) 폴더> figures
```

- `<capstone 분석 폴더>`에는 분석 코드(`engine.py`)와 결과 파일(`output/`)이 있어야 합니다. 이 폴더는 용량이 커서 저장소에 넣지 않았습니다.
- 코드가 읽는 결과 파일:
  - `output/step3_diagnosis_users.csv`
  - `output/step4_behavior_types.csv`
  - `output/step6_①같은개수.csv`
  - `output/step6_②예측.csv`
  - `output/step6_③레이팅.csv`
- 실행하면 그래프의 막대 합계가 위 표의 숫자와 같은지 확인하고(assert), 확인한 값을 화면에 출력합니다.
